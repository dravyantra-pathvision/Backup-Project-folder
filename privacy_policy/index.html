SECTION 01

1. Statutory Compliance & Purpose

DravYantra PathVision Technologies Private Limited ("DravYantra", "We", "Us", "Our") is committed to safeguarding the privacy, confidentiality, and security of personal, commercial, and telematics data collected through our fleet management platform.

This Privacy Policy is promulgated in strict compliance with India's Digital Personal Data Protection Act (DPDP Act, 2023), the Information Technology (Reasonable Security Practices and Procedures and Sensitive Personal Data or Information) Rules, global ISO/IEC 27001 ISMS standards, and the EU General Data Protection Regulation (GDPR).

SECTION 02

2. Comprehensive Categories of Data Collected

To provide commercial fleet tracking, automated compliance management, and predictive fuel analytics, DravYantra collects structured data across three core tiers:

1. Personal & Enterprise Data

• Full Name, Business Email Address, Mobile Phone (+91 format).
• Organization Name, Commercial GSTIN, Company Address.
• Job Designation, Department, Profile Photos.

2. Vehicle & Driver Profile Data

• Commercial Plate Number, VIN (Chassis Number), Engine Serial.
• Driver Full Name, Mobile Contact, Emergency Contacts.

3. System & Technical Diagnostics

• IP Address, Browser User-Agent, Mobile OS Version.
• Firebase Authentication Tokens, Active Session Records.
• System Audit Event Logs & Password Hashes.

SECTION 03

3. Document Verification & AWS S3 Bucket Security

During user onboarding and driver registration, users upload official compliance and identification documents. We enforce rigorous cloud security for all uploaded media:

  • Uploaded Document Artifacts: Scanned Driver Licenses, Commercial Vehicle Registration Certificates (RC), Vehicle Fitness Permits, Pollution Under Control (PUC) Certificates, Commercial Insurance Documents, and Fleet Avatars.
  • Amazon S3 Cloud Architecture: Binary document files are uploaded directly to our secure Amazon Web Services S3 bucket infrastructure (dravyantra-uploads).
  • Server-Side Encryption (AES-256): Every file written to AWS S3 is encrypted at rest using server-side 256-bit Advanced Encryption Standard (AES-256).
  • Pre-Signed Restricted Access: Document URLs are served exclusively through short-lived, pre-signed temporary links that require active session authentication, preventing public search engine indexing.

AWS S3 Encryption Standard Guarantee:

Document storage buckets (dravyantra-uploads) utilize IAM restricted access roles, SSL in-transit enforcement, and automatic AWS S3 bucket key encryption to protect your enterprise KYC documentation.

SECTION 04

4. Real-Time Telematics & Geolocation Data

Vehicles equipped with AIS-140 GPS trackers or OBD-II telematics adapters continuously stream telemetry data to our Node.js API servers:

  • Geographic Location Telemetry: Precise GNSS Latitude, Longitude, Altitude, Speed (km/h), and Heading Vector streamed at 5 to 10-second intervals.
  • Vehicle Mechanical Sensors: Ignition Status (ON/OFF), Engine RPM, Battery Voltage, Fuel Tank Percentage (%), Fuel Theft Alert events, Overspeed incidents, and Excessive Idling timeouts.
  • Purpose of Processing: Location and vehicle telemetry are processed strictly to render live fleet map views on CARTO Voyager GIS basemaps, calculate automated trip summaries, trigger geofence push notifications, and detect unauthorized fuel siphoning.
SECTION 05

5. Multi-Layered Technical Security Safeguards

DravYantra implements industrial cybersecurity protocols across every application layer:

  • Data Transmission (TLS 1.3 / HTTPS): All REST API requests, websocket streams, and database queries are encrypted in transit using 256-bit SSL/TLS 1.3 encryption.
  • Active Session Revocation: Admin and user sessions are validated against PostgreSQL active session tables. Revoking a session immediately forces a 401 Unauthorized response on target devices.
  • Database Encryption: Sensitive user records and system configuration hashes are stored in encrypted PostgreSQL database partitions.
SECTION 06

6. Third-Party Processors & Strict No-Sale Guarantee

STRICT NO-SALE GUARANTEE: DravYantra PathVision NEVER sells, rents, leases, or monetizes personal records, driver documents, or vehicle telematics data to third-party ad networks, data brokers, or marketing firms.

We share data strictly with essential infrastructure sub-processors required to deliver the platform:

  • Amazon Web Services (AWS): Cloud compute infrastructure (EC2) and encrypted document storage (S3).
  • Firebase (Google LLC): Identity authentication & OAuth 2.0 token validation.
  • OpenStreetMap & CARTO: Map tile infrastructure for rendering vector basemaps with international English labels.
SECTION 07

7. Data Retention & Data Erasure Protocols

We maintain clear retention schedules designed to minimize unnecessary data storage:

  • Historical Telematics Data: Raw trip breadcrumb trails and sensor logs are stored for 365 days for historical reporting and audit analysis.
  • Uploaded KYC Documents: Document files are retained for the duration of the active subscription plus 30 days following subscription cancellation.
  • Account Purge Execution: Upon receipt of a formal account closure request, all associated personal records and S3 document artifacts are permanently purged within 30 days.
SECTION 08

8. Statutory User Rights under DPDP Act 2023 & GDPR

As a registered user or fleet operator, you possess explicit legal data rights:

  • Right to Access & Review: View all registered profile details, active session logs, and uploaded vehicle documents via the Profile Screen.
  • Right to Correction: Request updates to mobile numbers, business emails, or re-upload updated driver licenses.
  • Right to Withdraw Consent: Withdraw consent for non-essential telemetry processing at any time.
  • Right to Grievance Redressal: Submit privacy concerns directly to our Data Protection Office.
