# Drav Yantra (drav_yantra_app)

Drav Yantra is a Flutter mobile application for managing drivers, vehicles, trips and fuel records. It pairs a Flutter frontend with a Node/Express backend that uses PostgreSQL (or Supabase) and can integrate with Firebase for admin features and storage.

## Quick Overview

- Frontend: Flutter app (located in this `frontend/` folder).
- Backend: Node/Express API (see `../backend/`).

## Prerequisites

- Flutter SDK (stable channel)
- Node.js (v16+ recommended)
- PostgreSQL or Supabase project for the database
- (Optional) Firebase service account JSON if using Firebase Admin

## Backend — Local run

1. Open a terminal and go to the backend folder:

	```bash
	cd ../backend
	```

2. Install dependencies:

	```bash
	npm install
	```

	Note on Windows PowerShell: if script execution is restricted, run `npm` via `npm.cmd`.

3. Create a `.env` file with required variables (examples used in the project):

	- `DATABASE_URL` — Postgres connection string
	- `SUPABASE_URL` and `SUPABASE_KEY` — if using Supabase
	- `FIREBASE_SERVICE_ACCOUNT_PATH` — path to Firebase admin JSON (optional)
	- `PORT` — server port (default 3000)

4. Start the server:

	```bash
	npm start
	```

The backend entrypoint is `server.js` and the API routes are in `backend/routes/`.

## Frontend — Local run

1. From the project root open the `frontend` folder:

	```bash
	cd frontend
	flutter pub get
	```

2. Configure Firebase (if used) and ensure `lib/firebase_options.dart` is present. The app includes `firebase_options.dart` generated by the Firebase CLI.

3. Run the app on an emulator or device:

	```bash
	flutter run
	```

For Windows builds, use `flutter run -d windows`. For simulators/emulators use the appropriate device flag.

## Project Structure (important folders)

- `frontend/` — Flutter app source (`lib/`, assets, etc.)
- `backend/` — Node/Express API, controllers, services and routes
- `backend/config/` — DB and external service configuration

## Useful scripts & files

- Start backend: `cd backend && npm start`
- Flutter run: `cd frontend && flutter run`
- Backend main: `backend/server.js`
- Backend routes: `backend/routes/`

## Notes

- The backend uses `express`, `pg` (Postgres), `@supabase/supabase-js`, and `firebase-admin`.
- If you plan to use Supabase or Firebase, ensure credentials are set in the backend `.env` and any generated client config files are updated in the frontend.

If you update environment variables or add new services, document them here and in the corresponding `backend/` config files.
